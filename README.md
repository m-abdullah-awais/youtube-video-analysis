# YouTube Video Summaries

A local web app that fills the Description column of a YouTube video spreadsheet with AI summaries generated by the vidIQ MCP, following a summary template you define.

> Status: in development (V1).

## What it does

1. Connect your vidIQ account.
2. Upload a CSV or Excel file of your videos.
3. Confirm which columns hold the video link and the description.
4. Write a summary template (for example: Summary, Key Points, Topics).
5. Run the batch and watch progress per video.
6. Download the completed spreadsheet with every summary in the right row.

## Tech stack

- Next.js (App Router) with TypeScript
- Tailwind CSS and shadcn/ui
- SheetJS for CSV and Excel
- Model Context Protocol SDK for the vidIQ MCP connection
- Node built-in SQLite for local job state
- Vitest for tests

## Getting started

Requirements: Node.js 24 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000.
